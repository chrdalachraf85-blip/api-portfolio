# GitHub Profile Portfolio

A small web app that displays a GitHub user's profile and public repositories. It loads the `chrdalachraf85-blip` profile on startup, then lets you search for another GitHub username or filter the displayed repositories by name.

The app uses JavaScript's `fetch` API to retrieve profile and repository data directly from GitHub. Repository cards show details such as description, stars, forks, language, and last update. Loading and error states are included.

## Run locally

Open `index.html` in a browser. An internet connection is required to load GitHub data.
